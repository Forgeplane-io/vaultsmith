Genuine native-app captures with synthetic fixtures. The baseline was captured
before changing the client. Screenshots supplement the native session checks;
they do not establish server logout by themselves.

## Capture conditions

- Base source: `0854d99289ce1857c37a680f186be45e333b3b69`.
- Before: production client unchanged; regression/browser tests edited only.
- After: the same base plus the seven-file implementation/test/documentation
  diff listed in [verification.json](verification.json). That file records exact
  diff identities, measured screenshot dimensions/checksums and native outcomes.
  Publication adds only this evidence directory after the recorded captures.
- Google Chrome 156.0.8078.48; viewport 1440 × 1000, device scale factor 1;
  `https://localhost:18443/`. Full-app capture height follows the rendered state
  and can exceed the viewport.
- Role: synthetic lane-only delegate. Fresh owned Redis/Keycloak/local-TLS
  fixture and isolated Chrome profile for each source state.
- Interaction: ordinary and attested re-key, owner removal, Clear, remove only
  the readable CSRF cookie, open a second app tab, then sign out from the
  original tab. Captures contain no values, proofs or credentials.

Both source states passed the native checks. After the fix, the browser journey
requires both the signed-out heading and an unauthenticated native session read.
A controlled negative run lost only the client response after actual logout;
the explicit heading assertion correctly rejected its retry/error UI.

## Repeatable checks and gaps

Build with the repository's Node version, then follow the
[native fixture and Chrome instructions](../../../integration/README.md#interactive-and-concrete-chrome-run).
Use only the absolute context path generated by the owned fixture. Do not expose
or reconstruct that context or install its test certificates globally. Stop the
fixture after testing; owned profiles, contexts and raw private logs were removed.

Mobile, other browsers, true browser restart/session restoration and production
providers were not exercised. Stale-cookie Decrypt/Generate UI states are not
pictured; unit coverage exercises current-cookie mutations and Generate. No
layout or styling changed; retained empty/cleared workbench captures were
byte-identical before and after.
